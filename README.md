# Ferramentas de faturamento e expedição

- `index.html`: coletor de etiquetas para o celular (Chrome do Android).
- `conferencia/index.html`: app de conferência para o PC.
- `central-de-documentos/index.html`: formulários internos (liberação de pedidos e instrução financeira).
- `consolidador/index.html`: consolidador de ordens de separação e etiquetas das caixas.
- `inicio/index.html`: página inicial com todos os apps.

Os dados ficam num banco protegido por login. Estes arquivos não têm dados: sem entrar com a conta autorizada, não mostram nem gravam nada.
